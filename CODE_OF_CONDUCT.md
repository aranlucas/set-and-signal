# Code of Conduct

We want Set & Signal to be a useful, welcoming project for people of every
background and training experience. Participate with patience, assume good
intent, and focus feedback on the work rather than the person.

Harassment, discrimination, threats, doxxing, sexualized behavior, and deliberate
disruption are not welcome. Maintainers may remove content or suspend
participation when needed to keep the project safe.

Report a serious incident privately through the security contact described in
[SECURITY.md](SECURITY.md). Please include links, dates, and enough context to
investigate while protecting anyone involved.
